# JARVIS

**Голосовой помощник и игровой напарник для Windows.** Открывает приложения, отвечает через локальную модель, хранит заметки и реагирует на события CS2. С тёмным интерфейсом, сферой, треем и горячими клавишами.

Создатель: **geeorge42_alt01 on ROBLOX** · [GitHub](https://github.com/geeorge4/JARVIS) · Версия **2.3.0**

> Проект развивается. Это рабочие исходники и автономный установщик файлов приложения, а не комплект со всеми нейросетями и музыкой. Известные ограничения указаны ниже.

## Что умеет

| Для компьютера | Для общения | Для игр |
|---|---|---|
| Поиск и запуск приложений | Локальный чат через Ollama + Qwen | Реакции на киллы и эйсы CS2 |
| YouTube, сайты, папки и параметры Windows | Микрофон через faster-whisper | Раундовые и финальные гимны из ваших файлов |
| Сценарии и избранное в «Выполнить» | Piper; отдельный необязательный XTTS | Музыка меню, игровой режим |
| Таймеры, заметки, скриншоты | Имя и память пользователя | Журнал матчей и базовый отчёт сессии |
| Поиск текста на экране через Windows OCR | Жирный, курсив и блоки кода | Экспериментальные события War Thunder |

- **Ctrl+J** — показать JARVIS поверх окон; сочетание меняется в настройках.
- **Ctrl+Shift+R** — окно «Выполнить» с поиском приложений.
- **Ctrl+Shift+O** — небольшой оверлей чата.
- Закрытие окна скрывает его в трей. Для завершения: значок JARVIS → **Выйти**.
- Фоновый микрофон можно полностью выключить. Распознавание работает локально после загрузки модели.

## Скачать и обновить

**[Скачать InstallUpdates.exe](https://github.com/geeorge4/JARVIS/raw/refs/heads/main/dist/InstallUpdates.exe)** · [Все файлы сборки](https://github.com/geeorge4/JARVIS/tree/main/dist)

1. Закройте JARVIS через трей → «Выйти».
2. Запустите `InstallUpdates.exe` и выберите папку JARVIS.
3. Нажмите **Установить / обновить**, затем запустите `JARVIS.exe` в этой папке.

Пакет встроен в EXE: установщик **не обращается к сети**, не запускает PowerShell, не меняет антивирус, не добавляет автозагрузку и не выполняет скачанные команды. Для следующей версии скачайте новый EXE. SHA-256 опубликован в `dist/SHA256SUMS.txt`; это контроль целостности, не цифровая подпись издателя.

Настройки, активация, история и заметки находятся в `%LOCALAPPDATA%/JARVISASSISTENT`. Установщик их не перезаписывает; папки моделей и личная музыка тоже сохраняются. В случае ошибки записи установленные файлы приложения откатываются. Установщик сам не закрывает программу, не повышает права и не перезапускает её.

По умолчанию предлагается существующая `C:\Program Files\JARVISASSISTENT` или `%LOCALAPPDATA%/Programs/JARVISASSISTENT`. Для Program Files могут понадобиться права администратора. При установке в другую папку создайте ярлык на находящийся в ней `JARVIS.exe` через меню Windows.

**Важно:** установка на новый ПК распаковывает приложение. Python, библиотеки, Ollama, модели и музыкальные файлы не включены. Для полностью готовой среды выполните первый запуск ниже. EXE не подписан сертификатом; отсутствие предупреждений SmartScreen/Defender не гарантируется. Не отключайте защиту и не добавляйте исключения ради установки.

## Первый запуск на новом ПК

Нужны Windows 10/11 x64 и **Python 3.12 x64 с Tcl/Tk**, установленный с [python.org](https://www.python.org/downloads/windows/). В папке приложения выполните:

```powershell
py -3.12 -m venv Python
.\Python\Scripts\python.exe -m pip install -r requirements.txt
```

Команды показаны для пользовательской папки с правом записи. `JARVIS.exe` распознаёт как `Python/pythonw.exe`, так и `Python/Scripts/pythonw.exe`.

### Локальный голос и микрофон

Ознакомьтесь с [лицензиями компонентов](NOTICE.md) и [карточкой голоса Denis](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD). Затем, если согласны с загрузкой этих моделей:

```powershell
.\Python\Scripts\python.exe installer/prepare_models.py
```

Этот отдельный скрипт скачивает **файлы моделей**, не установщики и не команды: Piper Denis и faster-whisper Base. Он выбирает Piper только если движок ещё не настроен. Загрузка требует интернета; последующая работа голоса локальна. При отсутствующих моделях микрофон/озвучка недоступны, текстовые команды остаются.

XTTS — дополнительная настройка для опытных пользователей: `requirements-xtts.txt`, отдельное окружение `xtts-runtime`, модель `xtts-model`, разрешённый образец `xtts-reference.wav`. Личный образец автора и веса XTTS не опубликованы. На свежей установке рекомендуем Piper.

### Локальные ответы ИИ

Загрузите Windows standalone ZIP из [официальных выпусков Ollama](https://github.com/ollama/ollama/releases), распакуйте его так, чтобы существовал `Ollama/ollama.exe` в папке JARVIS. Сохраните также вложенные библиотеки Ollama. Модель скачивается отдельно:

```powershell
$env:OLLAMA_HOST='127.0.0.1:11435'
$env:OLLAMA_MODELS=(Join-Path $PWD 'models')
.\Ollama\ollama.exe serve
```

В другом терминале той же папки:

```powershell
$env:OLLAMA_HOST='127.0.0.1:11435'
.\Ollama\ollama.exe pull qwen3:4b-instruct
```

Это несколько ГБ; размер зависит от версий модели и рантайма. После завершения начальной настройки JARVIS умеет сам поднимать свой локальный сервер на `127.0.0.1:11435`. Используется локальная модель, платный API-ключ не нужен. Скорость зависит от компьютера; XTTS и ИИ могут заметно нагружать систему.

### Активация и приватность

Активация — локальная демонстрационная функция, не платная подписка и не надёжная система лицензирования. Для полного режима подходит `activation-1`; без ключа доступны YouTube и вопросы. Ключи встроены в открытый код. MIT-лицензия предоставляет права независимо от этого интерфейса.

Не публикуйте содержимое `%LOCALAPPDATA%/JARVISASSISTENT`: там могут быть личные заметки, имя, история чата и настройки. Само приложение использует интернет для открытия сайтов и первоначальных загрузок; локальный ИИ, OCR и STT не требуют облачного сервиса.

## Игровые интеграции

### Counter-Strike 2

Встроенный приёмник слушает только `127.0.0.1:38477` и проверяет секрет GSI. Текст для конфига можно получить из исходников:

```powershell
.\Python\Scripts\python.exe -c "from cs2_ace import config,token; print(config(token()))"
```

Сохраните выведенный конфиг в `game/csgo/cfg/gamestate_integration_jarvis.cfg` внутри папки CS2 и перезапустите игру. Не публикуйте секрет GSI. В меню настроек есть проверка связи.

**Музыка не распространяется.** Добавляйте только разрешённые вам аудиофайлы локально в `round-drops/`:

| Файлы PCM WAV | Событие |
|---|---|
| `drop-1.wav`, `drop-2.wav`, … | Случайный гимн раунда, без повторов подряд |
| `match-perfect-world.wav` | Дополнительный вариант за раунд с шансом 50%, если не играл предыдущим |
| `match-win.wav` | Победа во всём матче |
| `kill.wav` | Каждый зарегистрированный килл, усиление ×2 с ограничением пиков |
| `ace.wav` | После гимна при эйсе |
| `menu.wav` | Главный экран игры, 30% амплитуды |

Для звука килла и музыки меню используйте **PCM16 WAV**. Названия раундовых фрагментов можно описать в локальном `round-drops/clips.json`. При отсутствии файлов новые установки не включают соответствующие звуковые функции по умолчанию. Уже существующие настройки сохраняются.

### War Thunder

Экспериментальный разбор текстовых сообщений `localhost:8111/hudmsg`: аварии, уничтожения, попадания и исход боя. Срабатывания зависят от языка и состава событий. Фраза *Skill issue, back to the garage* показывается отдельным окном JARVIS, оригинальные надписи игры не заменяются. В эксклюзивном полноэкранном режиме оверлей может быть не виден. В настоящем бою новые реакции ещё требуют проверки.

### Ограничения

- Анализ экрана — **OCR текста**, не распознавание игровых объектов и не полноценное зрение.
- Анализ сбоев читает журнал Windows и метаданные дампов, но **не декодирует дампы**.
- Guardian использует доступные датчики. FPS требует отдельно обновляемого CSV PresentMon.
- Сессионный отчёт учитывает наблюдаемые киллы/смерти, карты и примерное время; пропущенные события неизвестны.
- Pixel Gun 3D не интегрирован: подходящий публичный API событий не найден.
- Автоматического анализа видеоповторов и автонастройки графики пока нет.

## Разработка и сборка

```powershell
py -3.12 installer/build.py
.\dist\InstallUpdates.exe --verify
py -3.12 -m unittest discover -s tests -v
```

Сборка использует встроенный компилятор .NET Framework 4.x Windows, Python stdlib и собственные исходники. Публикуются `InstallUpdates.exe`, `JARVIS.exe`, `jarvis-app.zip` и SHA-256. Сеть для сборки не требуется. CI проверяет исходники и собирает пакет на Windows; выпуск публикуется из ветки main.
