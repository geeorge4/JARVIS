# Примеры команд JARVIS

| Команда | Результат |
|---|---|
| открой YouTube | Браузер и «Приятного просмотра, сэр» |
| открой Steam | Поиск приложения, затем резервный протокол Steam |
| открой Telegram | Поиск через AppOpener |
| обнови список приложений | Обновление локального индекса |
| который час | Время |
| поставь таймер на 5 минут | Напоминание, пока JARVIS работает |
| запиши заметку купить молоко | Локальная заметка |
| покажи заметки | Последние заметки |
| прочитай экран | Один снимок основного экрана и OCR |
| объясни ошибку на экране | Объяснение распознанного текста через локальный ИИ |
| проверь сбои Windows | Последние события системного журнала |
| заметка о матче проверить гранату на B | Игровой журнал |
| покажи игровой журнал | Последние записи |
| отчёт сессии | Наблюдаемая статистика CS2 |
| начать игровую сессию | Новый отчёт |
| что за гимн | Название последней музыки |
| история гимнов | Последние десять треков текущего запуска |
| повтори гимн | Повтор последнего фрагмента |
| останови музыку Джарвиса | Гимн и отложенная реплика эйса |

Сценарии и собственные фразы настраиваются в «Конструкторе». Фактически доступные действия перечислены во вкладке «Команды». Большинству локальных команд нужен полный режим демонстрационной активации. Команды не дают модели произвольный доступ к терминалу.
