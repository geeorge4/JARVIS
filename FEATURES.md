# Возможности и статус

- Windows Tk-интерфейс: сфера, нейрочат, команды, конструктор и настройки.
- Сфера с одной голубой палитрой; пауза анимации при игровом режиме/Guardian.
- Трей, задачи Windows, глобальные горячие клавиши и мини-оверлей.
- Избранное и недавние приложения, поиск AppOpener, ручные сценарии.
- Локальный Ollama/Qwen, сохранение истории, имени и явно запомненных сведений.
- Локальный faster-whisper Base, активация словом Джарвис, остановка записи после паузы.
- Piper и необязательный XTTS; текстовые ошибки озвучки.
- Настройки характера, громкости/скорости и фонового микрофона.
- Жирный текст, курсив, команды и блоки кода без исполнения в чате/оверлее.
- Таймеры, заметки, скриншоты и открытие сайтов/папок/приложений.
- OCR экрана по запросу; чтение журнала перезагрузок Windows без декодирования дампов.
- CS2 GSI: киллы, эйсы, исходы раундов и матча, своя музыка и история гимнов.
- Отдельный звук килла, отдельная музыка главного меню; без модификации клиента.
- Игровой журнал и приблизительный отчёт наблюдаемой сессии CS2.
- Экспериментальные реакции War Thunder на текстовые события localhost:8111.
- Монитор доступных ресурсов; необязательный FPS через CSV PresentMon.
- Локальный InstallUpdates.exe сохраняет пользовательские настройки и ресурсы.

Не реализованы: зрение по изображению вместо OCR, декодирование crash dump, события PG3D, анализ видеоповторов, полный установщик всех нейронных зависимостей на новый ПК. Обработка игровых событий проверялась синтетическими тестами; покрытие реальных режимов зависит от данных игры.
