# JARVIS для Android

Самостоятельное приложение для Android 6.0 и новее. Версия 1.1.0.

В разделе **Раскидки** сохраняй свои карточки для любых карт CS2. Укажи карту, название и способ броска, при желании приложи скриншоты прицела и приземления. Поиск работает по карте, названию и описанию. Команда `раскидки инферно` откроет подборку сразу. Можно править и удалять карточки, отмечать избранные и проверять себя в режиме тренировки. Библиотека хранится на устройстве отдельно от ПК. Скриншоты открываются из выбранных файлов, поэтому сохраняй исходные изображения.

- Команды текстом, время и дата, открытие YouTube и настроек Android.
- До 100 заметок, которые остаются на телефоне между запусками. В разделе «Заметки» нажми «Добавить» или выбери запись для редактирования и удаления.
- Таймер на секунды или минуты с отсчётом в приложении. Системное уведомление после закрытия приложения не запланировано.
- Голосовой ввод через установленную службу Android. JARVIS просит её использовать офлайн-режим, но поддержка зависит от службы. Проверь распознанный текст и нажми «ОК».
- Озвучка при наличии офлайн-голоса русского языка в системном движке синтеза.

Приложение выполняет встроенные команды. Генеративный чат, Ollama и голос Дениса относятся к версии для Windows.

Скачай `JARVIS-Android.apk` со страницы выпусков и открой его на телефоне. Это пробная сборка с отдельной подписью, не выпуск Google Play. Android может запросить разрешение установки для браузера или файлового менеджера, из которого открыт APK.

Для сборки нужны JDK 17, Python 3, Android SDK Platform 35 и Build Tools 35.0.1.

```text
python mobile/build.py --platform PATH_TO_ANDROID_35 --tools PATH_TO_BUILD_TOOLS --signing-key PATH_TO_PRIVATE_PREVIEW_KEY --output JARVIS-Android.apk
```

Сохраняй ключ подписи локально. Для обновления установленного APK Android требует ту же подпись.
